# Markdown Visualizer

A simple Streamlit application to upload and visualize Markdown files.

## Features
- Upload `.md` files.
- Render Markdown content in a clean, wide layout.
- Toggle to view raw Markdown source code.

## Getting Started

### 1. Prerequisites
Ensure you have Python 3.8+ installed.

### 2. Installation
Clone this repository and install the dependencies:
```bash
pip install -r requirements.txt
```

### 3. Run the App
Start the Streamlit server:
```bash
streamlit run app.py
```

## Usage
1. Open the app in your browser (usually `http://localhost:8501`).
2. Upload a `.md` file using the file uploader.
3. View the rendered content.
4. (Optional) Check "Show Raw Content" in the sidebar to see the original source.
